D. Glossary

IAPMEI
Agência para a Competitividade e Inovação (Portuguese innovation agency)
Vale Inovação
Innovation voucher program (75% subsidy for SME AI projects)
Merit Score (MP)
Evaluation metric: MP = 0.50 × A (Coherence) + 0.50 × B (Impact), scale 0-10
ROC
Revisor Oficial de Contas (Certified Public Accountant), mandatory for applications
SCQA Framework
Situation-Complication-Question-Answer (McKinsey storytelling method)
NPV
Net Present Value (discounted cash flow over 3 years)
VAB
Valor Acrescentado Bruto (Gross Value Added), economic impact metric
